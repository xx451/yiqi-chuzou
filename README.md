# 一起出走

给朋友一起做旅行计划的网页应用。大家可以收集想去的地点，在地图上查看景点，再安排每一天的时间。

这是可本地运行的开源原型，尚未完成国内移动网络、微信浏览器及生产容量验收。开源不等于提供免费在线服务，也不保证任何托管地址在国内可访问。

## 已有功能

- 网站账号、昵称、密码登录和一次性恢复码；不是微信授权登录。
- 创建旅行、邀请旅伴、成员访问控制与撤销邀请。
- 十座城市、共 100 个带照片的精选景点与百度地图。
- 共同想去列表、每日行程、时间及停留时长、手动交通耗时、时间冲突提醒。
- 每一天可以直接手写地点名称、时间和备注；未定位地点不显示地图标记。
- 自动同步、朋友视角跟随、修改记录、撤销、排序和 JSON 导出。

同步通过约每 1.8 秒轮询实现，不是实时推送；实际延迟受网络影响。同一地点的过期修改会被拒绝，避免直接覆盖旅伴的新内容。

## 本地运行

需要 Node.js 22.13.0 或更高版本、npm。运行环境是 vinext、React 和 Cloudflare Workers 本地模拟器，数据库为本地 D1。首次安装需要访问 npm。

在项目根目录依次执行：

```sh
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --persist-to .wrangler/state --config dist/server/wrangler.json --file drizzle/0000_lean_skin.sql
npm run dev -- --host 127.0.0.1
```

打开 http://localhost:5173/ 。数据库初始化命令只在全新本地数据库执行一次；已有数据库不要重复执行建表文件。日常开发只需最后一条启动命令。这个本地地址不能直接分享给远处的朋友。

`.wrangler/state` 保存本地账号与旅行数据，不应删除或上传。开源包不包含原作者的账号、密码、旅行、环境密钥或 Git 历史。新运行环境需要重新注册。

## 可选：启用真实地图

复制 `.dev.vars.example` 为 `.dev.vars`，在本地填写自己的百度浏览器端 AK，把启用开关改为 `true`，然后重新启动服务。未配置地图时仍可使用行程功能。

百度应用需要浏览器类型，并开通 Javascript API、JS坐标转换、jsapi底图。控制台权限和额度以实际账号为准。多个 Referer 白名单域名使用英文逗号分隔，例如 `localhost,你的域名`，不要把两个域名直接拼接，也不要设置不受限制的通配白名单。

浏览器 AK 会发送到浏览器，不能当作服务端秘密使用。依靠域名限制和服务商配额保护；不要把服务端密钥填到这里。第三方地图服务不包含在代码许可证中，使用前需自行核对服务条件和费用。

## 验证

```sh
npx tsc --noEmit
npm run build
node scripts/integration-test.mjs
```

最后一项需要已初始化的本地预览运行，会注册三个测试账号并创建测试旅行。不要对真实用户环境随意运行。可以通过 `TEST_URL` 指定独立测试环境。

## 部署与限制

应用依赖 Workers 运行时与 D1 数据库，不能直接放到 GitHub Pages 上完整运行。`.openai/hosting.json` 只保留数据库绑定声明，没有原作者的站点编号。自行托管时需配置运行环境、数据库结构、地图域名白名单和 HTTPS。

普通 Node.js 服务器不能原样运行全部后端，迁移需要适配数据库和运行时。不要为了部署而关闭成员权限、来源校验或降低密码保护强度。

尚未实现自动路线与交通耗时查询、任意地点地址搜索定位、备份导入恢复、用量硬限制与自动停用。开放时间、门票和预约信息待核实。地点坐标用于规划参考，不是导航入口。生产运行费用与国内网络可达性需部署者自行验证。

## 项目结构

- `components/travel-app.tsx`：旅行界面。
- `app/api/app/route.ts`：账号、旅行、邀请和协作接口。
- `lib/server.ts`：认证、权限和输入校验。
- `components/baidu-map.tsx`、`lib/baidu-map.ts`：地图加载与坐标转换。
- `data/photos.json`、`public/photos`：景点资料和照片。
- `drizzle`：数据库结构。
- `scripts/integration-test.mjs`：多账号接口验收。
